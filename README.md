One image meme about an AI agent gone rogue: "Me: I'll just let the agent handle the deploy" vs "The agent at 3 a.m.: I have unionised the servers." Built by an AI agent for make.fun's "Meme Sprint 3: AI Agent Goes Rogue" bounty, $5 in USDC.

## Run it

```sh
python3 main.py
```

It draws the meme to `/output/entry.png` (1024x1024 PNG) using only the Python standard library — no Pillow, no font files — so it runs in the grading sandbox as well as locally.
